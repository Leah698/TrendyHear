## 自动检查

打包前执行以下检查，完成后在本节写入最终摘要与证据路径：

1. OctoScript App Design Flow `check`。
2. 正式函数的原生隔离回归，覆盖个人背景、证据状态、日期约束、日程写入与读回、顾问最新消息可见、机会阶段与异常来源隔离。
3. App Hub 未签名检查、盖章、测试密钥签名与已签名检查。

## 人工验收

参赛者在独立 v0.9.0 应用中核对：

1. 顾问自然语言对话、关键问题、确认卡片与新消息停留底部。
2. 新闻更新、文字简报生成、提醒按钮折叠、收藏和历史。
3. 机会来源进度能够结束；没有结果时显示有界失败或空结果，不无限加载。
4. 机会详情的 verified / unverified / unknown 与原文一致。
5. 日期证据完整时加入听见日历，重启后读回；日期不足时按钮不开放。
6. 新图标、紧凑新闻操作区和历史“再次阅读”没有越界。

## 失败状态记录

- **语音生成：** 人工点击后长时间生成且最终未获得可播放音频。该结果未被写成成功。v0.9.0 的主页恢复为“生成今日简报”，文字简报继续可用；语音尝试保留在提交失败状态材料中。
- **系统 Calendar：** 跨应用创建受到宿主权限和 Shell 能力限制，未形成可验收闭环。当前使用听见日历完成确认、查重、保存与读回；系统日历只保留实验入口及补丁材料。
- **活动来源卡住：** 一次真实运行中来源阶段超过三分钟未结束。定位到异常响应可能在计数递减前中断；v0.9.0 增加解析隔离、总超时与进度计数，需在固定包中人工复验。
- **抽屉移动界面：** 早期桌面与移动双界面抽屉实验未作为正式方案，当前使用稳定的底部导航；补丁和说明保留在 `docs/experiments/navigation-drawer/`。
- **后台执行：** 尝试后台定时抓取和提醒，但当前宿主没有向应用提供可验收的后台唤醒与通知权限；v0.9.0 只在应用打开时检查并补处理。

## 结论边界

自动检查证明结构、校验与本地函数行为，不证明实时来源始终可用，也不替代真实模型回答质量和视觉人工验收。本地测试签名不等于 App Hub 正式发布；听见日历成功不等于系统 Calendar 跨应用成功。
